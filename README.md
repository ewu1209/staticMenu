# Static Menu

A full-screen static menu for the Empire TV displays.

## Update the menu

Replace `menu.jpg` with the final menu image and keep the same filename, or update
the image filename in `index.html`. The display centers the full menu and preserves
its original aspect ratio without stretching or cropping. Black margins appear
only when the browser viewport and image have different proportions.

Use a high-resolution source image for sharp text on large TV displays. Display
scaling does not restore detail missing from the source image.

GitHub Pages deploys automatically whenever changes are pushed to `main`.
